// PHILOSOPHY

The data decides the model. The infra decides whether the data ever arrives.

I treat eval as a first-class system, not a notebook. If an ablation can't tell us whether the data moved the model, the data didn't ship.

Currently going deep on RoPE, attention, autoregressive/diffusion architectures, distillation, and quantization. See Works for my recent public projects.

AGENT SYSTEMS

MCP + Agent Harness

Built MCP servers and a custom agent harness (planner/executor loop, tool registry, eval harness) indexing 10+ sources: agent traces, code repos, wikis, runbooks, application logs. Adopted across 4+ teams, cutting debug cycles by 80%.

Role: AI/ML Data Engineer @ Amazon AGI
Stack: MCP, planner/executor loop, tool registry
SYNTHETIC DATA

Terminal-Task-Gen

Plug-and-play CLI producing SFT-ready synthetic terminal-task trajectories matching the nvidia/Nemotron-Terminal-Corpus schema. Three phases: skill-based task generation, Terminus 2 agent loop in tmux + Docker, filter + sharded parquet output.

Role: Solo build
Stack: Pydantic, Qwen3/Llama, HF TRL, Docker
View on GitHub
PRETRAINING CORPUS

Parameter-Golf-LM

8B-token cross-source-deduplicated pretraining mixture for OpenAI's Parameter Golf tiny-LM challenge. Blends FineWeb-edu, StarCoder, and OpenWebMath; MinHash-LSH dedup; retokenized with the baseline SentencePiece vocab. Drop-in for the reference train_gpt.py.

Role: Solo build
Stack: PyTorch, Hugging Face, FineWeb
